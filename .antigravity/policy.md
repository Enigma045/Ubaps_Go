# Antigravity Assistant Working Policy

This project follows a strict **"Always Plan and Confirm"** workflow as requested by the user.

## Rules of Engagement

1.  **Mandatory Planning**: Every user prompt must be met with an `implementation_plan.md`.
2.  **Explicit Confirmation**: No code changes or non-read-only commands shall be executed until the user provides explicit approval (e.g., "Approve", "Proceed", "Continue").
3.  **Audit Logs & Notifications**: All critical business logic changes must include corresponding `user_logs` and `notifications` to maintain the integrity of the Bursary Notification System.
